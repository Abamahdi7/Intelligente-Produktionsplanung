# Intelligent Production Planning (Simple Python Model)

##  Overview

This project presents a simple prototype of an intelligent production planning assistant, developed as part of an application project for InVIDO.

The goal is to demonstrate how production orders can be structured, prioritized, and processed more efficiently using a basic decision-support approach.

---

##  Project Objective

In modern production environments, multiple orders must be handled simultaneously, often without a clear prioritization strategy.

This project aims to:

- Improve decision-making in production
- Reduce inefficiencies caused by multitasking
- Provide a clear order execution sequence for workers

---

##  Concept

The system follows a simple process:

1. Input production orders  
2. Assign priorities based on experience  
3. Sort orders based on priority  
4. Provide clear output for workers  

This represents a simplified version of a potential intelligent production assistant.

---

##  Features

- Add production orders
- Assign priority levels (1 = high, 5 = low)
- Sort orders using a basic algorithm
- Display organized task list for workers

---

##  Example Workflow

Orders → Prioritization → Sorting → Worker Output
